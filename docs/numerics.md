# 数值约定和保守阈值

## 精确收益

删除超重物品后，以保留物品的编号 `i=1..n` 应用论文附录 B.1 的整数扰动。
原始输入下标另外保存。所有收益、收益差以及效率交叉相乘都使用有符号 `__int128`。
运算前将可用正数范围限制为 `2^124`，不可达状态独立编码为 `-2^126`，
不可达项不参加普通加法。

预处理检查单件扰动收益、总扰动收益及效率比较的乘积。
设总扰动收益为 `P`、交换表半径为 `L`，分配表前还检查
`(P+1)(8L+16) <= 2^124`。输入总重量和原始总收益另行用溢出检查累加。
不满足约定的输入以异常结束。

高瘦矩阵的均匀采样使用商和余数分解；若余数与样本索引的乘积可能超出 `size_t`，
则使用 `unsigned __int128` 中间值，避免大索引下的静默回绕。

有限收益前缀之后使用斜率 `-(2P+1)` 作凹延拓，保持隐式矩阵结构。
在一次仅增加重量的扩展中，累计新增件数不超过 `2L`。
输入解的已选物品与当前阶段候选物品不重叠，因此使用不存在物品的虚拟解收益小于 `-P`，
不能压过任何真实部分解。核心扩展显式保存实际数量上限：空重量组不产生源，矩阵搜索
跳过最早源之前及最后一个源的物理范围之后的行，每条 AP 也在实际数量上限处截断。
由于虚拟候选不能击败任何真实候选，这些截断不会丢失真实最优见证。
输出时仍检查实际数量。此规则也用于删除物品的反向更新。

## 常数的来源

生产代码采用 `C = 2^25`，并将表半径与独立的 `2*w_max^2` 上界取小。
这是保守常数，不是通过实验调出来的阈值。平方根及上取整采用整数计算。
使用 `h = bit_width(2*w_max)`，它不小于 `log2(2*w_max)`。

依据：[Jin 附录 B.3](https://arxiv.org/html/2308.04093v2#A2.SS3)、
[Bringmann–Wellnitz §4](https://arxiv.org/pdf/2010.09096)。
Jin 说明，对于其证明中使用的均匀重数多重集，可以去掉通用稠密子集和界中的重数对数因子。
本项目用更保守的数值重新核算这一化简，见 [均匀重数界](uniform-bound.md)：
密度系数可取 `2^30 log2(2|X|)`，区间系数可取 `4+2^24`。

本实现只需 `r <= 2W` 的情形。取每种重量恰好 `r` 件的 `X`，有
`|X| <= 2W^2`，故 `log2(2|X|) <= 2h`。取 `C0=65536`：

- `C0^2 = 2^32 > 2*2^30`，足以满足该密度条件。
- 区间系数与 `C0^2 h` 的比值小于 `0.004`。
- 子集和证明中的 `Nd/Σ(X)` 至多为 `4/(C0^2 h)`，小于 `0.1`。
- `Σ(X) >= C0^2 Wh/2 > 100W`。

这些不等式为该支持集阈值提供了余量。对各重数求和、以及把上一排名块的满额条件
转换为重数条件，分别至多引入因子 2；代码的 `2^25` 大于所需的 `131072`。
首阶段的初始 hint 大小直接使用实际重量种数，后续阶段才使用收缩阈值。

重量分层的常数可从无重数集合的稠密结果估计。设支持集大小为 `s`，相应倍数间隔
至多 `4Σ(S)/s^2`，可命中的区间左端至多 `339844 W^2/s`。
`2^21` 已能同时覆盖密度条件、区间长度和从另一多重集中取得倍数块的余量；
代码进一步使用 `2^25`。详细的交换框架见
[Chen–Lian–Mao–Zhang §3](https://arxiv.org/pdf/2307.12582)。

这些常数非常大。在可直接实验的规模下，经常由 `2W^2` 截断决定表宽，重量分层也可能只有一层。
测试另以已证明安全的全局半径注入多层划分，验证阶段衔接；不修改生产阈值。
均匀重数界的核算包括内部子集可能不再均匀时的处理。

## 确定性着色

隔离颜色族的悲观估计器乘去共同分母后，用整数计算并验证每轮覆盖超过一半集合。
集合平衡也完全使用整数。设 `k=ceil_sqrt(ceil(b/h))`，令
`d=k^2+(k+1)^2`。两个方向的潜势分别乘以 `2(k+1)^2/d` 和 `2k^2/d`，
交换方向则交换两因子。每个集合的两项初值都为整数尺度 `S=b+1`，
每次更新的除法向上取整。

两因子的平均值为 1，所以按整数潜势差选择方向后，未取整的总潜势不会增加。
每条集合关联边至多引入 2 个单位的取整误差；共有至多 `mb` 条边，故最终整数总潜势
不超过 `2mS+2mb <= 4mS`，并且始终是精确有理潜势的上界。
乘法前检查该全局界与最大因子的乘积适合内部整数范围。

令 `t=(k+1)/k`。若某集合最后的数量差达到 `D=8*ceil_sqrt(bh)`，
则其一项精确归一化潜势至少为 `t^D/cosh(log t)^b`。
当 `b>=h` 时，`log t >= 1/(k+1) >= sqrt(h/b)/3`，
`log cosh(log t) <= 1/(2k^2) <= h/(2b)`，故该项至少为 `exp(13h/6) > 4m`，
与总潜势上界矛盾。`D>=b` 的情况直接任意二分即可。
实现还逐集合检查这一整数证书，以捕获编程错误。

因此本实现的着色、收益计算和边界计算都不依赖浮点舍入。
