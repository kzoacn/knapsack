# 交付验收核对

依据 `implementation-plan.md`、用户确认的纯 C++20 要求，以及后续明确接受的
`O(n+W^2 log^5 W)` 复杂度标准。以下不把通过测试等同于证明复杂度。

| 要求 | 当前证据 | 状态 |
| --- | --- | --- |
| C++20 核心、测试、实验程序 | `CMakeLists.txt`、`include/`、`src/`、`tests/`、`bench/`；无 Python 项目代码 | 已实现；需支持 `__int128` 的编译器 |
| 输入及整数范围 | 公共头文件、README、`numeric.hpp`、`numerics.md` | 已明确，范围不足抛异常 |
| 最优收益和原始物品回溯 | `solver.cpp::finish`、独立 `validate_solution`、对拍 | 在支持范围内通过验证 |
| 空输入、零容量、全部可装入／全部超重 | 求解器早期分支及固定／随机测试 | 已覆盖 |
| 独立枚举和容量 DP | `baseline.cpp`、1,000 组小实例 | 已对拍 |
| 确定性预处理及分组 | median-of-medians、候选截断、有限候选排序 | 已实现并核对操作 |
| SMAWK 与压缩输出 | 普通矩阵枚举对照、高瘦矩阵、十亿行压缩测试 | 已实现并验证 |
| HintedKnapsackExtend 的条件性正确性 | 所有并列最优见证检查、有／无数量上限、多着色独立 DP | 已通过当前验证 |
| 两层确定性着色 | 整数悲观估计器、向上取整的整数潜势和证书 | 已实现并有数值说明 |
| 阶段衔接与剪枝条件 | `solver.cpp`、`numerics.md`、`uniform-bound.md`、多重量层测试 | 已实现并核对依据 |
| 失败用例复现 | 对拍失败打印完整输入、收益差异和随机种子 | 已实现 |
| 资源不足／分配失败 | 资源限制测试；测试进程逐次注入 475 个分配失败位置，检查异常和释放 | 已覆盖当前实例的分配路径 |
| CLI 与样例命令 | `app/main.cpp`、`examples/small.txt`、CTest CLI 测试 | 已通过 |
| 数据生成与 CSV 基准 | `bench/`；控制容量、分布、强制重复比例 | 已实现 |
| 性能及内存报告 | 原始 CSV、`validation.md`、进程 RSS 高水位 | 已记录，口径明确 |
| 改变 n、W、重复重量及容量 | 基础 6 个配置和分布／容量 27 个配置，三种算法对照 | 已记录一致收益 |
| 普通和 sanitizer 检查 | 最终 Release 与 ASan/UBSan 日志 | 两种构建均 7/7 通过 |
| 大索引采样 | `EvenRowSampler` 和大整数边界测试 | 中间乘积溢出风险已修复并验证 |
| `O(n+W^2 log^5 W)` 最终时间界 | `complexity.md` 的逐项计费及独立审查 | 达到用户确认的复杂度标准 |

论文 `log^4` 界与当前实现的差异作为交付限制保留，不再是用户确认标准下的阻塞项。
当前交付已按修订后的标准通过验收。
独立审查及其适用范围见 [independent-review.md](independent-review.md)。
