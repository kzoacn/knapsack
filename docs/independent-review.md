# 独立复杂度审查：当前通用扩展器不能按 Lemma 4.8 的界验收

2026-09-21。独立子代理先在临时目录完成审查，随后由主代理复核并纳入项目；这不是外部同行评审。

交付说明：用户随后明确接受 `log^5` 版本。本报告保留与论文 `log^4` 界的差异，
不再作为当前验收标准下的阻塞项。

## 结论与边界

1. `hinted.cpp` 的 `origin` 传播与论文定义 4.3 的 `S'[i]=S[z[i]]\V` 一致；没有发现该处实现偏离论文而额外制造源复制。句柄共享减少集合复制量，不减少后续矩阵的实际列数。
2. 下述 b=2 输入族使**当前** `extend_hinted`/`tall_smawk` 控制流程需要 `Ω(N log² N)` 次矩阵访问，N 为表长。因此它不能在所有通用 hinted-extension 输入上达到 Lemma 4.8 在 b=2 时要求的 `O(N log N)`。这个结论来自矩阵及递归路径推导，不来自有限测量拟合。
3. 构造中每个非空 hint 的初始 q 都有限，所有非空 handles 初始都被引用。因此仅在 `small()` 前过滤不可达/未引用 handles 不能修复该反例。有限数量截断也不足：可令每个函数的 `max_count=floor(N/w)`，所有相关矩阵仍保持相同行区间。
4. **这不是生产 `solve_paper` 的 `Ω(W² log⁵ W)` 下界。** 构造的公共重量 1 有 Θ(N) 件、最大使用重量 K，N=16K²，因而不满足生产每组最多 2K 件的组合限制；它也没有证明生产 DP 能生成这里的 q/hints。生产最终目标仍可由额外结构证明或算法修正挽救。
5. **这不是论文存在性定理错误的证明。** 它指出当前具体实现以及将每轮当前源数直接替换为初始 `|I^(j)|` 的计费不足。论文可能存在另一种矩阵实现、共享方式或额外摊还论证；本文未找到这样的补充。

论文参照：[arXiv v2 §4.3](https://arxiv.org/html/2308.04093v2#S4.SS3)。论文先按隔离着色划分初始源，再逐颜色组合，并在 Lemma 4.8 的证明末尾按初始 `|I^(j)|` 给每次 singleton 调用计费。这个替换需要额外依据。

## 当前实现可直接证明的上界

记 N=2L+1。单次 singleton 的当前非空源数为 A，矩阵块的行列数为 R_g,C_g。当前代码有

`O(N + sum_g C_g [1+log(ceil(R_g/C_g))]) <= O(N + A log N)`。

若每函数物理数量至多 M，拆分不连通区间后进一步有

`O(N + A [1+log(M+1)])`。

每个隔离实例 A 可以达到 Θ(N)，即便它起初仅有很少高收益源。按 O(log N) 个着色、b² 个颜色直接相加，加上隔离族构造，得到

`O(N b³ + N b² log² N)`。

外层把 hint 分成 O(b/log N) 个大小 O(log N) 的颜色类，直接得到通用扩展 `O(N b log³(Nb))`。结合已有阶段参数，仓库所写 `O(n+W² log⁵ W)` 是保守上界；本审查没有把它证明为生产下界。

## 多星构造：完全图控制隔离着色

取 K=4^h，N=16K²，函数编号 f=0,...,K-1，其重量 w_f=f+1。对每个无序对 {a,b} 建立一个大小为 2 的 hint；按 a 外层、b 内层的顺序放到前 K(K-1)/2 个源位置。其余位置 hint 为空且 q=-∞。特别地，hint {0,f} 位于源 z=f-1。

对于 b=2，当前整数隔离估计器的每个已出现邻点向它的颜色贡献同一罚分 4，因此每个待处理完全图分量的顶点依次循环染成 0,1,2,3。第 j 轮（从 0 编号）满足

`h_j(f)=floor(f/4^j) mod 4`。

剩余未隔离边的两端具有相同的前 j 个四进制位，形成互不相交的完全图。故一共恰有 h 轮。空 hint 只在第一轮被移除，不影响颜色选择。

第 j 轮令

`m=K/4^(j+1), s=4^(j+1)=K/m, d=N/m, alpha=K, beta=s`。

选取恰好 m 个本轮高收益根：

`f_l=s*l+s/4, z_l=f_l-1, l=0,...,m-1`。

它们对应 {0,f_l}，公共函数 0 染为颜色 0、专属函数 f_l 染为颜色 1，且在此前各轮均未隔离。不同轮选到的 f 不重复。

设公共函数（重量 1）的收益为

`Q_0(x)=-alpha*x²`。

设这些根的输入收益为

`q[z_l]=alpha*z_l²-alpha*s*d*l²`。

其它完全图边源（包括未选中的星形边）都设为有限的

`q=-H, H=100*K*N²`。

每个非空 hint 都因此可达且被初始 origin 引用。所有整数大小均为 K 的多项式，所需字长 O(log K)；构造没有借用超多项式收益。

## 第一颜色后的源区间

在第 j 个隔离实例中，处理公共颜色 0 后，对于 t>=K，返回值恰为

`q_j(t)=-alpha*t² + max_l [2*alpha*z_l*t-alpha*s*d*l²]`。

由于相邻 z_l 之差为 s，相邻候选的交点位于 t=d(l+1/2)。因此内部根 l 的 origin 获得长度 d 的整数区间

`d(l-1/2) < t <= d(l+1/2)`，

端点依当前左列优先规则归属，只有 O(1) 的取整差别。首尾根的区间截断到数组边界。

证明低收益源不会干扰：在本轮颜色 0 中，高收益根只允许公共函数；所有其他候选的起始收益为 -H。把下述专属函数改写为物理增重 y=w*x 的二次式，利用 z<K、d*l<N、alpha=K、beta<=K、0<=y<N，可得其绝对值至多 6KN²。因此低收益源的候选至多 -94KN²，低于首个高收益公共根的值（后者至少 -KN²）。所以公共 AP 在桶扫描中不会被它们剪掉。非星形边的辅助源位置 >=K-1；本轮未选中的低收益星形边，其首个非零四进制位为 2 或 3，也位于本轮最早高收益根之后。这些辅助源都在公共 AP 覆盖的后缀中。实验程序逐一检查了 t>=K 的收益及 origin 是否等于上面的闭式表达式。

## 第二颜色的凹函数与矩阵

对本轮根 l 的专属函数，重量 w=z_l+2，设

`Q_f(x)=2*w*[alpha*z_l-(alpha+beta)*d*l]*x-beta*w²*x²`。

这些函数都严格凹，Q_f(0)=0。未选中的其他函数可用 Q_f(x)=-x。每函数令物理数量上限为 floor(N/w)，不会截掉任何表内可达源到目标；以当前连续凹尾表示也完全足够。

现在处理本轮颜色 1。对属于根 l 的源 t，其扩展到目标 i 的目标函数为

`A(i,t)=q_j(t)+Q_f((i-t)/w)`。

在该根的源区间内部，它作为 t 的二次函数的连续唯一极大点为

`t*(i)=d*l + beta/(alpha+beta)*i = d*l+i/(m+1)`。

对于一个固定余数，离散最优列是离这个位置最近的源，平局取较小源。下述区域中的 t* 严格处于源区间内部并满足 t*<i，所以不受数组边界、物理数量或下三角不可行区影响。

## 当前 tall_smawk 的查询下界

只考虑 m>=32 的轮，选取 l in [m/8,m/4] 中的 Θ(m) 个根。它们的重量 w=Θ(K)。对每个余数：

- 源区间长 d=N/m，故列数 C=d/w+O(1)=Θ(d/w)，且考虑端点取整后可保守取 C>=240。
- 行范围从首个源到表尾，故行数 R=Θ(N/w)。
- 因此 R/C=Θ(m)。连续的源之间无空隙，不会触发代码的矩阵拆分。
- 当前 `tall_smawk` 取 C 个等间隔采样行，相邻采样行之间距离 Θ(m)。

考察物理目标 i in [N/3,5N/12]。在这个固定比例的目标区间中，t*(i) 从 d*l+d*m/[3(m+1)] 增加到 d*l+5*d*m/[12(m+1)]，都位于该根源区间内部。除去两端取整，其最优列累计变化 Θ(d/w)=Θ(C)。

相邻采样目标相差 Θ(m*w)，而 t* 的变化率为 1/(m+1)，所以相邻采样点的最优列只改变 O(1)；在这里更可界为 0 或 1。因此有 Ω(C) 个采样间隔的端点最大列不同，每个间隔行数为 Θ(m)。

关键是 `src/monge.hpp` 中 `tall_smawk` 的 `interpolate`：当端点最大列不同且区间长度>1时，它必须做至少一次列比较，并递归到两个半区间。至少一个子区间的端点最大列仍不同；沿这一子区间直到长度 1，至少经过 `floor(log2(length))=Ω(log m)` 层。即使交点恰好位于中点，也有一个异列子区间继续递归。因此每个这样的采样间隔至少产生 Ω(log m) 次 oracle 访问。

于是每个余数矩阵需 Ω(C log m)，对 w 个余数合计 Ω(d log m)，对选取的 Θ(m) 个根合计

`Ω(N log m)`。

最后 m_j=4^(h-j-1)，对 m_j>=32 的 Θ(h) 轮相加：

`sum_j Ω(N log m_j) = Ω(N*h²) = Ω(N log² N)`。

这已经超过 b=2 时的 O(N log N)。全部代价发生在颜色 1 的矩阵阶段，因此后续 AP 桶剪枝不能减少已发生的访问。

## 实验与复现

`bench/multistar_probe.cpp` 为独立 probe，直接链接现有 `build-release/libknapsack.a`；先运行完整 `extend_hinted`，再按相同颜色重放并打印分轮计数，且逐状态核对第一颜色后的闭式包络。上述渐近论证不依赖这些有限计数。

```sh
cmake --build build-release --target knapsack_multistar_probe
./build-release/knapsack_multistar_probe 64
```

当前 probe 使用 N=16K²；默认使所有辅助非空 hint 的收益为 -100KN²。可用 `--ghost` 将辅助源设为不可达作对比；正式论证使用默认有限版本。

已复现 K=16、64、256。K=64 时 N=65536，三个颜色 1 调用当前源数分别为 65536、65533、65521，初始高收益根数仅为 16、4、1。完整矩阵访问为 2,233,254。先前 N=4K² 的试验也运行至 K=1024；报告的证明与最终 probe 统一使用 N=16K²。

## 如何恢复目标界

在通用输入上，不能只补一句“源句柄共享”或重新套用 `sum_j |I^(j)|=N`；本输入族排除了这种计费。至少需要下面一种实质变化及其证明：

- 改变多着色实例的求解/共享方式，避免它们各自在已扩张的 Θ(N) 个源上独立重复 Θ(log m_j) 深度的矩阵搜索；需要新的正确性不变量，不能任意把所有中间状态跨颜色逐点合并，因为同一重量在不同着色中可能已处理/未处理，凹函数的重复计数会破坏组合论证。
- 使用与上述 `tall_smawk` 不同、能利用跨来源生成结构的专门算法，并证明全部轮次的访问总量。
- 直接对生产排名 DP 证明一个额外限制，足以约束各矩阵的传播源总量及 `R/C`；该限制必须排除本构造。仅有“每个 hint 至多 b 个元素”不能做到；仅知 `max_count<=2W` 还需结合排名块参数作全阶段计数。

本次未找到已经证明正确、能立即落地恢复 log⁴ 的局部补丁。不应在发现这一缺口后随意删传播源或只保留初始源，这会破坏合法的多颜色扩展。

## 主代理复核

已核对整数隔离估计器在等重数完全图上的四进制循环着色、公共颜色后的二次包络、
第二颜色矩阵的极值点，以及当前插值递归的异列路径长度。
对于选定根范围，`d/w >= 240`，采样行间隔为 `Θ(m)`；在指定目标区间内，最大列总变化为 `Θ(C)`，
而相邻采样点最大列变化至多常数。因此异列采样间隔数为 `Ω(C)`，每个必须有 `Ω(log m)` 个递归层。
复现程序还检查了完整返回见证的重量、收益、数量和原始 hint 归属。
本复核维持报告的适用边界，不把通用子问题的反例扩大为生产全流程下界。
