# 核心扩展的计数实验

新增的 `knapsack_extension_probe` 直接计数隐式矩阵访问，不把墙钟时间当作复杂度证据。
它检查见证的重量、收益和 hint 条件；小型完整图实例另用逐原始源的独立容量 DP
枚举最优值，并保留是否存在违反 hint 的并列最优解这一标志。

## 两个颜色类

```sh
./build-release/knapsack_extension_probe 8
```

设根源数为 `K`、表长 `N=16K^2`、`a=K-1`、`d=N/K`。
只有 `0<=z<K` 的输入可达，收益为 `-a(d-1)z^2`，hint 为公共重量和专属重量。
公共重量为 1，收益函数为 `-a*x^2`。
根源 `z` 的专属重量为 `w=z+2`，收益函数为
`2*w*z*(a-N)*x-w^2*x^2`。这些函数均为凹函数。

第一次扩展后，根源的 hint 可以传播到全部 `N` 个位置。
第二次扩展的矩阵查询数据见 [extension-probe.csv](extension-probe.csv)。
在所测范围内，`queries/N` 从 9.73 增至 17.84；
`queries/(N+K*log2(N))` 从 8.65 增至 17.76。
它展示了直接复用“初始源数”进行单次计费需要额外论证。

这组只有两个有效颜色类，**没有构成整个小 hint 算法超过 `O(N log N)` 的反例**。
不能从这组有限测量断言论文定理错误。

## 多个隔离着色

```sh
./build-release/knapsack_extension_probe --graph 8
```

取 `K` 种重量 `K..2K-1`，为每一对重量建立一个大小为 2 的 hint，
固定种子打乱它们的初始位置，使用初始收益 `q[z]=-7z^2`。
每种重量的收益函数为 `-(w*x)^2`，数量上限为 `2K`，表长 `4K^2`。
这会实际经过多个隔离着色和逐点最大值合并。

结果见 [graph-probe.csv](graph-probe.csv)。测试中着色数从 1 增至 4，
矩阵查询数与 `N log N` 的比值没有增长。
因此它增强了多着色路径的正确性覆盖，但没有证明整体 `log^5` 上界是紧的。

## 有限数量优化

生产求解器显式向扩展器传递当前排名块的物品数量：

- 空重量组不产生候选源。
- 矩阵行区间限制在首个源到最后一个源的物理可达范围。
- 同一重量和余数下，若两个源的物理可达区间之间有空隙，则拆成独立矩阵。
- 每条 AP 在本源的数量上限处结束。

设该重量的数量上限为 `m`。拆分后，一个有 `c` 个源的块最多有 `c(m+1)` 行，
故其矩阵搜索可按 `O(c(1+log(m+1)))` 计费。
这一改进收紧了单次搜索界；本项目采用的整体 `log^5` 上界见复杂度审计，
不能仅凭计数实验宣称已达到论文的 `log^4` 界。
