# 实现复杂度审计

本实现采用 `O(n + W^2 log^5 W)` 的确定性时间上界。
下文给出当前实现的逐项上界；测试和计时作为独立证据，不代替渐近复杂度推导。
论文来源为 [arXiv:2308.04093v2](https://arxiv.org/html/2308.04093v2)。

## 已核对的组件

| 组件 | 代码 | 审计结论 |
| --- | --- | --- |
| 贪心边界 | `selection.hpp`, `solver.cpp` | 确定性 median-of-medians，避免对全部输入排序 |
| 同重量候选 | `solver.cpp` | 每侧保留前 `2W` 件；线性选择后仅排序保留项 |
| 普通矩阵 | `monge.hpp::smawk` | 隐式访问；普通行最大值的线性扫描界 |
| 高瘦矩阵 | `monge.hpp::tall_smawk` | `c` 个采样行加单调插值，`O(c(1+log(ceil(r/c))))` 次访问 |
| 单元素 hint | `hinted.cpp` | 按非空源分组、压缩区间及桶扫描；`O(L+L1 log L)` |
| 集合共享 | `hinted.cpp` | origin 作为不可变 hint 的句柄，更新时不复制整组 hint |
| 解的回溯 | `solver.cpp` | 持久节点记录，按实际扩展记录付费；不逐状态复制完整物品集合 |

高瘦矩阵实现先在至多 `c` 行运行普通 SMAWK。相邻采样行若有相同最大列，整个间隔直接输出；
否则只搜索两最大列之间的候选。每一插值深度的候选跨度总和为 `O(c)`，
深度为 `O(1+log(ceil(r/c)))`。输出相邻同列区间合并，避免枚举长区间。

固定宽度整数的分组使用稳定字节基数排序。收益运算的适用范围见 [数值约定](numerics.md)。
有限排名块还会按实际数量截断并拆分不可相接的源区间，将单次矩阵搜索中的
对数参数收紧为该重量的数量上限；见 [计数实验与优化](extension-probes.md)。

## 通用扩展的上界

小 hint 集合先用 `O(log L)` 个隔离着色划分输入，再逐颜色调用单元素扩展。
每次组合会把源 hint 的句柄传给新状态，因此不能直接把后续调用的非空源数
当作该隔离实例的初始非空源数。

测试 `components.cpp` 中包含一个最小观察：只有 `q[0]` 可达且其 hint 含两种重量，
首次扩展后，后续扩展的可用源可以覆盖全部 100 个状态。统计
`peak_singleton_sources` 专门记录这个变化。

对本实现直接逐次计费，小 hint 算法的保守上界为
`O(L*b^3 + L*b^2*log^2 L)`；经过外层平衡划分，得到
`O(L*b*log^3(L*b))` 的一般扩展界。再按各排名阶段的参数相加，
当前保守总上界是 **`O(n + W^2 log^5 W)`**。

这一保守上界是本次采用的验收标准。独立审查确认当前通用小 hint 实现不能直接按论文
Lemma 4.8 的更强计费验收，见 [审查记录](independent-review.md)。该结论没有证明生产
求解器必须付出五个对数因子，也不等于否定论文的存在性定理。

## 从扩展上界到完整求解器

令 `H=max(1,ceil(log2(2W)))`；不同取整方式只影响常数。

1. 输入验证、贪心边界和重量分组为 `O(n+W)`。每个重量的两侧仅保留前 `2W` 件，
   通过确定性线性选择后排序保留项，共 `O(n+W^2 H)`。
2. 小 hint 情形 `b=O(log L)` 的隔离族构造为 `O(Lb^3+|U|log L)`。
   最多 `O(log L)` 个隔离实例，各处理至多 `b^2` 个颜色，每次 singleton 为 `O(Llog L)`，
   合计 `O(Lb^3+Lb^2 log^2 L)`。
3. 大 hint 情形先分为 `O(b/log L)` 组，每组 hint 大小 `O(log L)`。
   加上整数平衡及句柄处理，一般扩展为 `O(Lb log^3(Lb))`。
   在生产调用中 `|U|<=W<=O(L)`，准备函数和集合的操作也包含在这些界内。
4. 每个排名阶段有正、负两个扩展。其半径 `L_j` 和 hint 界 `b_j` 满足
   `L_j b_j=O(W^2 H)`，且 `log(L_j b_j)=O(H)`。
   因此每阶段为 `O(W^2 H^4)`；最多 `O(H)` 阶段，合计 `O(W^2 H^5)`。
   物理半径截断及数量截断只会减少工作，不参与减少对数指数的论证。
5. 返回见证每项至多有 `b_j` 个非零计数。创建阶段间回溯记录每阶段 `O(L_j b_j)`，
   最终恢复原始物品及独立可行性检查为 `O(n)`。
   第二阶段的逐重量批量更新及逐层截断由重量层的数量／半径乘积界控制，低于上述主项。
6. `W>n_eligible^2` 的分支使用容量 DP。非平凡实例有 `t<n_eligible W`，
   故更新时间 `O(n_eligible*t)<=O(W^2)`；过滤及验证仍为 `O(n)`。

所以在文档约定的整数运算范围内，原始输入扫描与全部算法步骤合计为
`O(n + W^2 H^5)`。当 `W` 为常数时按 `H>=1` 解释。

## 数值与内存口径

- 均匀重数依赖已补充保守常数核算，见 [推导](uniform-bound.md)。
- 集合平衡已改为向上取整的整数潜势；其误差界及证书见数值约定。
- 内存以 [验证报告](validation.md)中的进程 RSS 高水位衡量，包含同时存活的回溯池及工作表。
  `max_states` 和 `max_trace_nodes` 分别限制单表和节点池，不能代替进程峰值口径。

公开接口在数值范围或资源限制不满足时报告异常。基准程序输出的是指定配置的实测结果，
不用于宣称已经获得论文的 `log^4` 时间界。
