# 验证与实测记录

日期：2026-09-21。环境：AMD Ryzen 7 8845H，WSL2 Linux 6.18.33.2，GCC 13.3.0，CMake 4.4.2。
Release 构建，单线程；每种算法和输入配置各启一个进程，重复三次，报告时间中位数。
这组计时没有同时执行构建或 sanitizer 测试。

## 正确性

- 最终 Release：CTest 7/7 通过。
- 最终 AddressSanitizer + UndefinedBehaviorSanitizer：CTest 7/7 通过。
- 完整求解器：1,000 组小规模随机实例与子集枚举及容量 DP 对拍；40 组较大实例与容量 DP 对拍。
- 单独验证回溯、并列最优解、相同比值、重复重量、空输入和整数／资源边界。
- 矩阵：500 组普通和高瘦 SMAWK 与逐行枚举比较；另检查十亿行隐式矩阵保持压缩输出。
- 大索引采样：直接检查超过 64 位中间乘积范围的取样位置，无需分配巨大矩阵。
- 核心扩展：700 组实例枚举所有最优见证，覆盖有／无物理数量上限，检查条件性契约和输出可行性。
- 新增不相接源区间的查询次数检查，以及多隔离着色完整图的独立 DP 契约测试。
- 着色：200 组隔离族、非平凡集合平衡和一般两层扩展；10 组安全多层划分验证阶段衔接。
- 额外验证 `n=1000, wmax=64, seed=42`，论文版与容量 DP 均返回 `107910`。
- CLI 对负容量、零重量、尾随非法输入返回状态码 2。
- 分配失败：paper、exchange、容量 DP、枚举分别检查 269、195、9、2 个故障位置，共 475 个；未返回不完整解或遗留自有分配。
- 独立审查的多星复现已加入 CTest，检查返回见证和公共颜色后的闭式包络。

## 容量与重复重量覆盖

[distribution-results.csv](distribution-results.csv) 保存了 27 个配置、三种求解器、每种三次运行，共 243 行测量。
容量取总重量的 10%、50%、90%；均匀分布还分别强制 0%、25%、50%、75%、100% 的物品使用最大重量。
同时覆盖 correlated、subset、ties、duplicates 分布。三种求解器在全部相同配置上的收益一致。
强制重复比例是下限；CSV 的 `max_weight_items` 记录了随机生成后该重量的实际件数。

## 时间中位数

所有实例为 `uniform`、种子 42、容量为总重量的 50%。下表时间单位为毫秒。
原始 54 行记录在 [benchmark-results.csv](benchmark-results.csv)，六个输入实例在三种算法和全部重复中收益一致。

| n | wmax | 最优收益 | paper | exchange | dp |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 200 | 16 | 5291 | 2.726 | 1.396 | 2.127 |
| 200 | 32 | 10440 | 17.117 | 7.570 | 4.182 |
| 200 | 64 | 22047 | 59.799 | 31.368 | 8.033 |
| 1000 | 16 | 26655 | 3.266 | 2.150 | 63.886 |
| 1000 | 32 | 52579 | 28.073 | 16.506 | 129.104 |
| 1000 | 64 | 107910 | 190.945 | 108.974 | 273.795 |

此组规模下，交换 DP 对照版比论文版更快。论文版使用保守常数和更多的扩展步骤；
这些计时是性能快照；采用的 `log^5` 上界由独立的逐项计费支持，不能以计时替代理论证明。

`n=1000, wmax=64` 时，各进程 RSS 高水位为：

- paper：57524 KiB。
- exchange：47264 KiB。
- dp：266400 KiB。

RSS 包含进程的输入、工作表、回溯记录和运行时分配器；跨三次重复取进程高水位。
计时实验没有启用 `--verify`，以免把对照求解的内存混入该配置。

复现示例：

```sh
./build-release/knapsack_bench --algorithm paper --n 1000 --wmax 64 --seed 42 --repeats 3
```


有限数量截断与源区间拆分前的历史数据保存在 [benchmark-results-initial.csv](benchmark-results-initial.csv)。
同一 `n=1000, wmax=64, seed=42` 实例的论文版矩阵访问次数从 `28317252` 降至 `8879398`，
当前三次计时中位数为 `190.945 ms`；历史中位数为 `354.338 ms`。这是指定实例的实测改进，
不用于证明渐近阶的变化。
