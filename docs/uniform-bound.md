# 均匀重数界的常数核算

这是本项目采用的保守常数推导。依赖
[Bringmann–Wellnitz](https://arxiv.org/pdf/2010.09096) 的定理 4.1、4.24、引理 4.20，
及其定理 4.2、4.3 的组合方式；用途是落实
[Jin 附录 B.3](https://arxiv.org/html/2308.04093v2#A2.SS3) 的均匀重数化简。

记均匀多重集 `X` 的重数为 `r`、大小为 `n`、最大值为 `W`、总和为 `Σ`。
以下只需支持集大小至少 32 的情况；本项目实际应用中的下界远大于此。

1. 对均匀输入，稠密子集和定理 4.24 的证明可直接令 `X'=X`，略去重数分桶。
   保留较松的数值后，AP 长度条件的分母为 `33984*r*log2(2n)`，步长和最大值
   的系数仍可取 `4248`，没有重数对数因子。

2. 取 `α=2^21`、`δ=2^30 log2(2n)`。引理 4.20 及其组合估计给出保留集合 `R`，
   满足 `|R|<=n/4`、`Σ(R)<=Σ/4`，以及所有所需小模数的完备性。
   `δ >= 32α log2(2n)`。

3. 从 `X\R` 中重新选均匀集合 `A`。令 `k=max(1,floor(r/2))`。
   至少 `3n/(4r)` 种数值不超过 `4Σ/n`。
   某种数值剩余不足 `k` 件，需要在 `R` 中消耗至少 `r/2` 件；这样的种类至多 `n/(2r)`。
   因此，至少 `n/(4r)` 种小数值各剩余不少于 `k` 件。
   任选其中 `floor(n/(16r))` 种、每种取 `k` 件形成 `A`。
   有 `n/96 <= |A| <= n/16`、`max(A)<=4Σ/n`、`Σ(A)<=Σ/4`。
   剩余 `G` 因而满足 `Σ(G)>=Σ/2`。

4. 对均匀 `A` 应用第 1 步，取 AP 长度 `2W`。
   密度条件由 `2*96^2*33984 < 2^30` 保证。
   AP 步长系数至多 `4248*4*96=1631232 < 2^21`；
   最大值系数至多 `3262464`。
   因此区间覆盖需要的系数 `3262464+2*1631232=6524928 < 2^23`。

5. 可据此在无 almost-divisor 的均匀情形使用区间常数 `Cλ=2^23`。
   定理 4.1 的整除约化删除的是整种数值，故约化后的输入仍均匀，且至少保留原支持集的四分之三。
   按定理 4.3 的组合证明，得到倍数区间常数 `4+2*Cλ = 4+2^24`，
   并保留 `d <= 4rΣ/n^2` 的界。

本项目对支持集引理使用 `C0=2^16`。因 `r<=2W`，其前提保证原支持集至少
`C0*sqrt(log2(2W)/2)`；经过整除约化仍大于 32。
这补足了第 3 步取整和均匀子集选择所需的条件。
