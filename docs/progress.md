# 交付进度

验收：已按用户确认的 `O(n + W^2 log^5 W)` 标准完成。
用户在 2026-09-21 明确接受该上界；论文的 `log^4` 界作为差异记录保留。

## 交付内容

- 纯 C++20 库、CLI、实例生成器、CSV 基准程序和 CMake/CTest 工程。
- 独立容量 DP、子集枚举、交换 DP，以及论文框架下的精确求解器和物品回溯。
- 确定性线性选择、普通及高瘦 SMAWK、hint 传播、两层整数着色和排名／重量层更新。
- 有限数量截断、不相接源区间拆分、整数溢出检查与资源上限。
- 大索引采样的安全乘法及不分配巨大矩阵的边界测试。
- 数值约定、结构常数推导、实际复杂度证明、独立审查和性能原始数据。

## 最终检查

- Release：CTest 7/7 通过。
- AddressSanitizer + UndefinedBehaviorSanitizer：CTest 7/7 通过。
- 1,000 组小实例、40 组较大实例、组件契约和多重量层回溯验证通过。
- 475 个可控分配失败位置均经过异常／资源释放检查。
- 基础 6 个配置和分布／容量 27 个配置的三种求解器收益一致。

具体证据见 [验收清单](acceptance-audit.md)、[验证记录](validation.md)和
[复杂度审计](complexity.md)。
