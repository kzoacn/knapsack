# 论文实现计划

阶段：已按用户确认的 `log^5` 标准完成验收。实现语言为纯 C++20。

已接通库、CLI、C++ 对拍基线、核心组件、数据生成器和基准程序。
完整流程已接通并通过对拍；实际复杂度及与论文的差异见 [审计记录](complexity.md)。

论文：Ce Jin, *0-1 Knapsack in Nearly Quadratic Time*，
[arXiv:2308.04093v2](https://arxiv.org/html/2308.04093v2)，2024-04-01。

## 目标与交付物

实现论文框架下的确定性精确算法。用户在 2026-09-21 明确确认采用
`O(n + w_max^2 log^5 w_max)` 时间界作为最终复杂度验收目标。
论文原有 `log^4` 界保留为差异说明，不作为本次交付的阻塞项。
交付物包括 C++ 库、命令行程序、正确性测试、数据生成器、基准程序和实现说明。
核心、测试和实验代码均使用 C++20。

采用 CMake 构建，使用 CTest 调度测试；初期测试使用标准库实现。
基准程序输出 CSV，便于比较不同实例和实现版本。

## 接口与输入约定

- 输入：物品的正整数重量、正整数收益和非负整数容量。
- 输出：最优收益、对应的原始物品下标及总重量。
- 原始下标在预处理、分组及回溯期间保持可追踪。
- 空输入、容量为零、全部物品可装入、全部物品超重均作为明确的边界分支。
- 具体整数范围在实现数值层时确定，并写入公共接口文档。
  对收益累加、平局处理、比值比较和索引计算分别核算上界并检查溢出。
- 中间阶段标注各自的实际复杂度；达到最终审计条件后再声明实现了论文时间界。

## 实施顺序与验收

### 1. 规格及证明条件

建立模块契约和依赖表，记录数值范围、取整规则、不可达状态和相等值处理规则。
明确每个剪枝条件的证明依据，推导结构引理中常数的可用数值上界。

验收：每个将影响正确性的阈值都有来源或推导；尚未落实的条件显式记录。

### 2. 工程与独立基线

搭建库、CLI、测试及基准目标。实现小规模子集枚举和经典容量 DP。
使用固定随机种子，失败时打印完整输入、期望结果和实际结果。

验收：两种基线对拍一致；CLI 可读取实例并输出收益与选择结果；CTest 可统一执行。

### 3. 基础算法

实现预处理、精确整数比较、重量组收益表和批量更新，组装交换 DP 基线。
逐项测试普通 SMAWK 的结果及相等值规则。

验收：基础组件与朴素枚举比较一致，交换 DP 与两种独立基线对拍通过。

### 4. 核心扩展

实现压缩矩阵输出、单元素 hint 扩展、结果组合和确定性着色。
为各组件建立足够小、可枚举全部候选解的独立测试实例。

验收：返回的候选解始终满足可行性和收益一致性；需要最优性的状态满足模块契约。
`HintedKnapsackExtend` 的测试遵循论文 Problem 1 的条件性保证。

### 5. 完整管线与回溯

连接分层、各阶段更新和最终答案提取。用回溯记录恢复原始物品下标。
将内存生命周期、集合共享和中间表示纳入实现审查。

验收：最终收益与独立基线一致；物品下标唯一、重量不超容量、收益与输出相符。

### 6. 复杂度审计与实验

逐模块统计扫描次数、矩阵访问次数、候选区间数量、集合处理量和内存使用。
分别改变物品数、最大重量、重复重量比例及容量，保留可复现的实验配置。

验收：复杂度推导与实际数据结构操作一致；基准报告包含时间、内存和基线比较。
有限规模的计时结果作为性能证据，理论时间界另行审计。

## 重点测试

- 相同重量、相同收益、相同收益重量比以及多个最优解。
- 贪心前缀已最优、必须删除并加入物品才能最优的实例。
- 极端重量分布、大量重复重量、可达状态稀疏的实例。
- 负交换重量、不可达状态、阶段边界、区间端点和并列最大值。
- 所支持整数范围附近的输入、运算溢出和内存申请失败。
- 固定种子随机对拍及失败用例的永久回归测试。
- Debug 构建以及编译器支持时的地址、未定义行为检查。
